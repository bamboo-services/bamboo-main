自我介绍

你好呀，我是筱锋。这个小站是我的自留地，种着友情链接、生活随笔，还有一些关于代码的碎碎念。它不追求热闹，只求每一篇都对得起点开它的人。

我是一名后端工程师，日常与 Go、PostgreSQL 和 Redis 打交道；也喜欢前端，这个小站的前后端都出自我的手。工作之外，我喜欢逛博客、看动漫、研究各种有意思的开源项目。

写代码和种竹子一样，急不得，也停不得。

我在做什么

  • 维护这个小站和它的友链系统，让它一直安静地开着。
  • 写一些 Go 与云原生的实践笔记，记录踩过的坑。
  • 收集好看的独立博客，和朋友们交换链接。

如果你也喜欢写东西、喜欢折腾，欢迎通过上面的方式找到我，或者直接在友链页留下你的小站。

关于本站

「竹林小筑」是一个关于技术、生活与思考的个人博客。这里有 Go 与云原生的实践笔记，有独立博客的友情链接，也有一些关于代码与生活的碎碎念。

小站基于 Go + React 构建，前后端均出自博主之手。愿每一位到访的朋友，都能在这里找到一片清凉。
